# Repository to store my Jupyter Notebooks

## Notebook contents include:
- Python practice
  - Language fundamentals, data structures, functions, and small utilities
  - Data loading, cleaning, and lightweight preprocessing examples
  - Quick examples for debugging, testing, and idiomatic Python

- Machine Learning
  - Preprocessing and feature engineering pipelines
  - Supervised models (linear/logistic, tree-based, SVM) and basic neural nets
  - Model evaluation, cross-validation, metrics, and simple hyperparameter tuning
  - Examples using scikit-learn and occasional PyTorch/TensorFlow demos

- Natural Language Processing (NLP)
  - Text cleaning, tokenization, stopword handling, and basic normalization
  - Word embeddings and usage examples (Word2Vec/GloVe)
  - Transformer examples and Hugging Face fine-tuning for classification/NER
  - Sentiment analysis, topic modeling, and sequence tasks

- Utilities & experiments
  - Visualization recipes (matplotlib, seaborn), exploratory data analysis
  - Reusable helper functions and small benchmarking notebooks
  - Notes on reproducibility, runtime expectations, and data sourcing
